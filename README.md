# Coral Property — luxury real estate concept

Sito statico ispirato alla struttura editoriale di Douglas Elliman e adattato ai contenuti pubblici di Coral Property.

## Avvio locale

```bash
python3 -m http.server 4173
```

Aprire `http://localhost:4173`.

## Contenuti

- 14 proprietà di Porto Cervo e delle sue località pubblicate nel catalogo Coral Property
- filtri per vendita e affitto
- ricerca per nome e località
- homepage a pannelli, carosello, preferiti e menu mobile
- pagina interna dedicata per ogni immobile
- gallerie fotografiche reali e mappa della zona per ogni immobile
- cambio lingua italiano/inglese
- richieste tramite email, telefono e WhatsApp
- modulo dedicato alla valutazione degli immobili in vendita

I moduli preparano una richiesta completa nell'app email dell'utente. Telefono e WhatsApp aprono direttamente i rispettivi canali Coral Property.
